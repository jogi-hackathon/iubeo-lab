# 空の劣化レイヤー（WebGPU）

IUBEO の「空は見上げるほど不明瞭になっていく」という景観アイデアを、単体 HTML で試す実験です。WebGPU / WGSL のフルスクリーンシェーダーで、視点の高さに応じた圧縮アーティファクトと、砂漠にも海にも見える遠景の波を描きます。

## 起動

リポジトリのルートで静的サーバーを起動し、Chrome / Edge で開いてください。WebGPU 対応ブラウザが必要です（Safari など非対応環境では動きません）。

```bash
cd /path/to/iubeo-lab
python3 -m http.server 8000
```

<http://localhost:8000/sky-degradation/> を開きます。WebGPU が利用できない場合は、画面左下に理由が表示されます。

## 操作

- **視点の高さ / Y**: 落下して彼らから遠ざかるほど値を下げます。
- **見上げ角**: 空の層を画面内に見せます。
- **劣化スケール / N / 波の振幅 / 更新 Hz**: アーティファクトと遠景の見え方を調整します。
- URL パラメーター `y`, `p`, `d`, `n`, `w`, `f`, `hud` で初期値を指定できます。例: `?y=2.6&p=0.55&hud=0`

## 実装メモ

- 依存ライブラリなし。単一フラグメント相当の WGSL シェーダーで描画します。
- 視点の高さと画面上の向きから層座標を作り、8 / 20 / 44px の圧縮層を段階的に受け渡します。
- グラデーションの量子化、ブロック単位の擬似 DCT / DC ずれ、量子化境界のノイズを組み合わせています。
- `index.html` はプロトタイプの単独配布物です。ゲーム本体のシーンへ組み込んだものではありません。

## 検証の範囲

この実験は WebGPU の見た目・操作を比較するためのラボ成果物です。ヘッドレス環境での描画や実機 GPU 間の見え方は、ブラウザ・ドライバー・GPU ごとに別途確認してください。
